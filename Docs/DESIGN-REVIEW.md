# 设置页视觉检查

本次改动针对 Remote Vibe 的原生 macOS 设置界面。以清晰的信息层级、独特的遥控器展示和一致的交互状态为设计目标；Awwwards、Webby、FWA 是品质参考，未作获奖认定。

## 三轮迭代

| 轮次 | 检查发现 | 完成的调整 |
| --- | --- | --- |
| 1 | 原设置页缺少视觉主次，设备和编辑区联系弱 | 建立暖白、深绿与浅青柠配色；重绘两种遥控器；统一主窗口、动作编辑、连招设置及底部状态区 |
| 2 | 侧边音量标识对比度不足；图标比例不一致；动作名称重复出现 | 提高标识对比度；统一图标绘制尺寸；简化已保存摘要，增加键帽与动作说明预览 |
| 3 | 固定宽度在窄窗口产生横向滚动；键盘焦点需要明确反馈 | 两栏随窗口宽度调整，保持字号和控件高度；短窗口纵向滚动；补全按钮焦点绘制、禁用焦点行为和遥控器选中状态的辅助功能信息 |

第三轮生成 23 个隔离场景，覆盖 Google / 小米、单击 / 双击 / 长按编辑、文本、组合键、网页校验、固定语音键、连招页以及 900 / 1080 / 1280 宽度。只抽查关键截图，其余使用程序检查，避免反复图片识别。

## 验证方式

在项目根目录执行：

```sh
zsh Tests/preview-design.sh round-3
zsh Tests/test-button-gestures.sh
zsh Scripts/build-app.sh
git diff --check
```

预览直接复用实际视图及窗口容器，检查文档宽度与可视区域一致、输入框与按钮可接收焦点、语音映射保持只读；模拟连招控制器不访问钥匙串。现有回归测试覆盖手势时序、旧配置兼容、分手势草稿、文本、Fn、网页校验及恢复默认。

截图来自离屏 AppKit 渲染，原生控件的激活色受窗口激活状态影响。保留原生菜单、分段控件和文本编辑器。没有新增动画循环、网络资源或依赖，也未通过本次检查重新测试真实蓝牙录音和锁屏解锁。

## 0.4.4：统一墨绿色与按钮文字修正

操作按钮统一为墨绿色，遥控器选中键和动作预览同步使用深色底与白色图标；清除操作使用深红色。移除浅青柠配色及普通按钮的主次颜色分支。

原生有边框按钮不接受 `contentTintColor`，且系统会重设禁用标题的颜色。保留原生 `NSButton` 的边框、尺寸、焦点与点击处理，仅通过 `NSButtonCell.drawTitle` 绘制标题。活动窗口使用浅色文字；窗口失焦、系统按钮底色变灰时使用深色文字。图标按深浅两种颜色分别缓存。

本机 macOS 27.0.1 使用隔离控件进行像素对比度检查，覆盖启用、禁用、按下、动态标题和窗口失焦，也检查了原生下拉框、分段控件与复选框。自定义按钮实测启用文字对比度不低于 6.4:1、禁用文字不低于 3.2:1。未读取生成的预览图片。中英文设置页、手势回归与 App 构建通过；已在原运行位置试用。
