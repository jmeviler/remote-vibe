Remote Vibe — 同事试用包

用 Google / 小米遥控器自带的麦克风，在 Mac 输入文字。

这是面向有一定 Mac 操作基础用户的试用版。
需要能自行完成蓝牙配对、系统权限设置和微信语音配置；暂不适合零基础开箱即用。

一、先确认适用条件

• Apple Silicon Mac（M1 / M2 / M3 / M4 等 M 系列），macOS 15 或更新。
  Intel Mac、Windows，以及 macOS 14 或更早版本不适用。
• Google Chromecast Voice Remote，或小米 RC003 蓝牙语音遥控器。
• 已安装并登录微信，并有可在其他 App 中使用的“长按 Fn 语音输入”功能。
  仅有微信聊天窗口内的语音消息按钮不够。
  本包不附带微信，不提供独立语音识别服务。

二、首次安装（只做一次）

1. 解压本文件夹，双击「1-安装 Remote Vibe.pkg」。
   跟随 macOS 安装向导，输入这台 Mac 的管理员密码。
   安装完成后 App 会尝试自动打开，也可到“应用程序”打开 Remote Vibe。

2. 如果系统提示“无法验证开发者”：
   本包是尚未经过 Apple 公证的试用版本。
   确认文件来自项目 GitHub 发布页后，到“系统设置 → 隐私与安全性”，
   找到本次打开受阻的提示，选择“仍要打开”，然后重试。
   这是 macOS 自身的确认；不要关闭系统安全保护。
   公司管理的 Mac 如果禁止未公证应用，需要由 IT 放行。

3. 在“系统设置 → 蓝牙”中，将遥控器与这台 Mac 配对。
   配对模式请按该遥控器说明书操作；先断开它与原电视/盒子的连接。
   小米在列表中通常显示“小米蓝牙语音遥控器”，Google 显示“Chromecast Remote”。

4. 打开 Remote Vibe，在顶部“当前遥控器”选择你使用的型号。
   App 会连接已记住或系统已连接的所选型号，不会自动扫描新设备。
   未连接时可点“扫描遥控器”，每次最多扫描 20 秒；连上立即停止。
   如正在等待旧遥控器，先点“取消等待”，再手动扫描。
   第一次出现蓝牙权限提示时，点“允许”。
   在 App 点击“权限设置”，为 Remote Vibe 打开“辅助功能”权限。
   如需组合快捷键、滚动、常用文本等，再点“允许按键控制”，
   打开“输入监控”权限；如果系统提示重启 App，退出后重新打开。
   这些权限必须由这台 Mac 的使用者亲自确认，安装包不会替你授权。

5. 开启微信的长按 Fn 全局语音输入，并允许微信使用麦克风。
   微信的输入设备使用“系统默认输入”，或选择“Chromecast Mic”。
   小米同样使用这个设备名称，属于正常情况。
   若找不到“长按 Fn 全局语音输入”，请先确认你的微信版本/账号提供此功能。

三、开始说话

1. 查看窗口顶部就绪提示，确认遥控器、语音组件和辅助功能已就绪。
2. 点击需要输入的文本框，例如 Codex、浏览器或备忘录。
3. 按住遥控器的语音键，说一句话；松开，等待微信生成文字。
4. 一次最多约 55 秒；继续说话时，等本次结束后再次按住。

“微信试说说明”可查看微信设置和试说步骤。设备就绪不代表微信已能识别；
App 不读取识别结果，需要本人确认是否出字。
菜单栏显示当前版本，可手动“检查更新”并打开“发布说明与下载”。
检查仅在点击时联网，不会自动下载或安装。暂无正式发布版本时会明确提示。
已有语音组件时，下载发布页的 App-AppleSilicon.zip，按说明退出、备份并替换原 App；
无需卸载或重装驱动，也不重启音频服务。首次安装才使用完整安装包。
界面支持简体中文和英文，跟随系统语言；更改语言后重开 App。

只需用一只遥控器。更换时，在 App 顶部切换型号即可。
关闭设置窗口后，App 会继续在菜单栏运行。
下次使用：到“应用程序”打开 Remote Vibe。

四、自定义按键

点击配置图上的按键 → 选择单击、双击或长按 → 选择功能 → 点击“保存并生效”。
两种遥控器有各自的配置图，设置分别保存，不会互相覆盖。
可选回车、删除、Esc、方向、组合快捷键、滚动、换屏、换窗、常用文本等。
终端 / Codex CLI 的选项可使用方向键、回车、Esc、Tab、Shift + Tab；
新增“终端 / Codex CLI”分类提供数字键和 Control + C / G / O / R。
按当前屏幕提示操作：运行中 Tab 排队追加指令，Enter 可直接补充当前指令；
它们并不始终代表选项切换或确认。原来的 Google 中央 OK 默认是 Esc，不是回车。
语音键固定为按住说话；要撤销改动，点“恢复此键默认”，再保存。

Fn：功能列表选“Fn 按键（按住 / 松开）”，按住普通键保持 Fn，松开释放。
组合键：选“自定义按键 / 组合快捷键…”，勾选 Fn，再选方向键等主键。
Fn 的用途取决于系统和软件设置。若触发微信语音，使用微信当前选择的麦克风。
此 Fn 映射不会开启遥控器麦克风或切换系统输入。

Google 普通键也能说话：
• 在单击位选择“遥控器麦克风（按住说话）”，双击、长按均设为“未设置”，按下即开麦。
• 或给单击选择明确动作，再给长按选择“遥控器麦克风（长按后开麦）”，按住约 0.55 秒开麦。
• 松开后结束，沿用原语音键的输入流程。仅支持已验证的 Google ATVV 1.0；
  旧协议 Google 和小米继续使用原语音键。红外模式下不发送蓝牙事件的键无法改绑。

鼠标模式（0.4.5）：
• 在“普通键位”选一个普通按键，选择单击、双击或长按，再选动作列表首项“切换鼠标模式”。
  使用双击或长按时，单击需要明确动作（也可“不执行”），并遵循 Fn / 语音保持规则。
• 点“鼠标键位”单独配置四方向移动、左键点击和右键点击，再点“保存并生效”。
  默认方向键移动、中央键左击、返回键右击；其他键默认保留系统原功能。
• 用选定的按键和手势进入，再用相同手势退出；松开所有键后切换，退出恢复普通配置。
  切换键的所有手势在两个模式中自动保留。设置页切换键位页签只切换编辑内容，不切换运行模式。
• 按住方向持续移动并逐渐加速，松开停止；左右点击按一次触发一次。
  连续两次左击可双击；移动也可设为长按动作，不能设为双击。
• 菜单栏显示鼠标模式，也可点菜单“退出鼠标模式”。保存、断连、锁屏、休眠或
  切换遥控器会退出鼠标模式；重新启动始终进入普通模式。语音开始时停止移动。
• 两个模式、两种遥控器独立保存，不会自动覆盖已有普通键位。需要输入监控和辅助功能。

单击、双击和长按：
• 双击间隔为 0.3 秒；设置双击后，单击会等第二次按键。
• 长按阈值为 0.55 秒；达到后只触发一次，松开不再补发单击。
• 设置手势时，单击需选择明确动作或“不执行”，不能保留“原按键功能”。
• 即时保持 Fn / 遥控器语音不能叠加双击、长按；双击不支持保持式动作。
• 两种型号分别保存，旧单击配置保留；恢复默认会清除该键的双击和长按。

Google 默认：静音键回车；返回键删除；中央 OK 为 Esc；
主页换窗；YouTube 换屏；方向键保持方向。
小米默认：中央 OK 回车；返回键删除；其他普通键保留原功能。
回车能否发送，由你正在使用的软件决定。
小米暂未接入连招解锁。Google 的连招解锁默认关闭：
录制 8–16 次按键并重复确认 → 保存本机登录密码 → 练习 → 开始手动锁屏验证。
验证只向系统密码框发送一个测试字符，不按回车；清除字符并手动解锁，
确认看到了测试字符后才能启用。连招和密码保存在本机钥匙串。
此功能不支持重启 / FileVault 首次登录；无法确认系统密码框时不会输入。

五、遇到问题

• 显示未连接：检查型号和系统蓝牙配对，短按遥控器唤醒；需要时点击“扫描遥控器”。
• 不出现语音输入提示：检查 Remote Vibe 的辅助功能权限，及微信的 Fn 语音功能。
• 有提示但没有文字：检查微信麦克风权限、输入设备，并确认微信语音服务可用。
• 普通键有效、组合键无效：在 App 点“允许按键控制”，检查输入监控与辅助功能。
• 显示已有组件而安装停止：先退出 App，运行配套卸载包，再重新安装。
• 刚授权仍无效：菜单栏退出 Remote Vibe，再从“应用程序”重新打开。
• 公司电脑禁止安装或权限开关不可用：由 IT 处理设备管理限制。

六、安装了什么，如何移除

安装仅添加：
  /Applications/Remote Vibe.app
  /Library/Audio/Plug-Ins/HAL/RemoteVibeMic.driver
以及 macOS 安装器的标准安装记录。

没有开机启动项、后台 Web 服务或内核扩展。
安装和卸载会重启系统音频服务，正在播放的声音可能短暂中断。
不会更换默认扬声器；说话时临时切换默认输入，结束后尝试恢复。
这会影响跟随“系统默认麦克风”的其他软件：会议或录音可能切到遥控器声音。
使用期间，请在会议/录音软件内明确选择原来的实体麦克风。
如果软件只能跟随系统默认输入，请避免与遥控器语音同时使用。
退出恢复需原麦克风仍可用；强制终止或崩溃后，需重开 App 才能尝试恢复。
不能把当前版本理解为“对所有音频软件零影响”。

卸载：先在菜单栏退出 App，再双击「2-卸载 Remote Vibe.pkg」。
组件会移入 /Users/Shared/RemoteVibe-Uninstalled/ 下的备份目录，方便撤回。
确认不再需要后，可手动将备份移到废纸篓。
个人按键设置保留。若曾保存连招密码，请在卸载前到 App 清除连招与密码。

本包不含制作者的个人配置、常用文本、密码或录音。
App 不保存录音/转写；语音识别由微信处理，遵循微信自己的服务规则。

源码及许可证见随包的「源码与许可证」目录。
