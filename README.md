# Remote Vibe

把 Chromecast Voice Remote 变成 Mac 上的语音输入与快捷键遥控器。

原生 Swift / AppKit 应用，无 Web 服务、Electron 或第三方运行时。按键映射使用 macOS 原生 HID 接口，配置界面和蓝牙语音在同一个菜单栏 App 中运行。

## 使用

1. 在 macOS 蓝牙设置中配对 **Chromecast Remote**。
2. 启动 Remote Vibe，在设置窗口中点击遥控器上的按键。
3. 选择功能，点击 **保存并生效**。

全部 15 个物理按键都显示在界面中，包括侧边音量键。14 个普通按键可配置；语音键固定为按住说话。

| 按键 | 默认功能 |
| --- | --- |
| 语音 | 按住说话，松开结束 |
| 静音 | Enter 回车 / 发送 |
| 独立返回箭头 | Backspace 退格删除 |
| 中央 OK | Esc，取消 / 停止，长按不连发 |
| 主页 | 循环切换当前屏幕窗口 |
| YouTube | 切换屏幕 |
| 方向盘 | 上、下、左、右 |
| 其他按键 | 保留原按键功能 |

可选动作包括回车、退格、取消、方向键、Tab、空格、上下滚动、切换屏幕、切换当前屏幕窗口、输入常用文本、禁用和自定义快捷键。所有动作都可改绑到任意普通按键，已有的自定义配置优先于默认值。

自定义支持 Control、Shift、Option、Command 多选，与字母、数字、方向键、F1–F12 等组合。例如为某个按键配置 `Control + Shift + ↑`，界面会预览完整组合。下拉菜单也提供 Shift + Tab、Command + Tab / Command + Shift + Tab、Control + Tab / Control + Shift + Tab 常用组合。

Esc、组合键、换屏和换窗按一次触发一次，长按不连发。组合键触发后会释放模拟的修饰键，同时保留键盘上实际按住的修饰键。

映射作用于当前软件；Enter 是否发送以及快捷键的行为由该软件决定。点击保存后，配置会保存在本机，运行期间在遥控器重连后恢复映射。正常退出时撤销 App 仍在接管的按键，并保留其他工具后来做的修改。设置窗口可关闭，App 继续在菜单栏运行。

### 换屏与换窗

- **切换屏幕**：按屏幕排列顺序循环，激活目标屏幕最前面的可见普通窗口。当前屏幕按前台窗口占面积最大的位置判断，没有前台窗口时按鼠标位置判断。
- **切换当前屏幕窗口**：在当前屏幕可见的普通窗口之间按稳定顺序循环，包括同一应用的多个窗口；关闭或移走的窗口会移出循环。
- 成功后鼠标移入目标窗口，不点击，方便继续滚动。不会移动窗口、恢复最小化窗口或主动跨桌面空间（Spaces）。
- 只有一块屏幕、没有目标窗口、权限不足或窗口无法激活时，在设置窗口的状态区域显示原因。语音期间不执行换屏、换窗或组合快捷键。

窗口操作使用公共辅助功能接口和当前可见窗口清单，无需屏幕录制权限。未提供可操作辅助功能窗口、或窗口位置无法唯一匹配的应用窗口会被跳过。不提供“回输入框”：macOS 没有所有应用都支持的通用接口。

### 常用文本

选择一个按键，将动作设为 **输入常用文本**，填写文字并保存。每个按键独立保存一段文本，支持多行、中文和 emoji。先把光标放入目标输入框，再按遥控器：按一次粘贴一次，不自动按回车。

仅向可通过辅助功能确认的可编辑、非密码输入框粘贴。语音、锁屏或连招录入期间暂停；焦点变化时取消。App 短暂使用剪贴板，约 0.6 秒后恢复原内容；期间用户新复制的内容会保留。剪贴板无法完整备份或超过 32 MiB 时不执行。未提供可编辑辅助功能元素、禁用粘贴或处理粘贴过慢的应用可能无法使用此动作。

### 连招解锁

在 **连招解锁** 页设置：

1. 点击 **录制连招**，按遥控器 8–16 次，点击 **确认录制**，再重复一次。除语音和电源外的按键均可参与。
2. 使用 **练习** 检查手感；练习只核对按键，不锁屏、不输入密码。
3. 在安全输入框中填写本机登录密码并保存。连招与密码分别保存到本机钥匙串，不同步到 iCloud，不写入偏好、日志或剪贴板。
4. 如需真实解锁，点击 **开始手动锁屏验证**，在 90 秒内自行锁屏并输入连招。App 只尝试把系统密码框替换为一个测试字符，不按回车。清掉测试字符，使用键盘正常解锁后，在 App 中确认结果。
5. 确认看到测试字符后，才能手动打开 **开启连招解锁**。

长按只算一次；相邻按键间隔超过 3 秒或按错时从头输入，连续 5 次错误暂停 30 秒。录入和锁屏识别期间暂时接管普通按键，结束后恢复。关闭设置窗口或离开此页会结束录制与练习。

真实解锁默认关闭。只有确认系统处于锁屏、目标进程是 Apple 签名的 `loginwindow`、焦点是其安全密码框且钥匙串可读时，才会定向替换密码并提交一次。每次锁屏最多提交一次，不自动重试，也不会退回全局密码输入。无法确认条件时请使用键盘正常解锁。

此功能依赖当前 macOS 的锁屏输入和辅助功能行为，**未经本机手动验证不能视为可用**。不支持重启 / FileVault 首次登录；App 或系统更新、修改连招或密码后需要重新验证。关闭功能保留设置；**清除连招与密码** 仅删除本 App 的解锁钥匙串项目。

## 语音输入

收音来自**遥控器自带麦克风**。App 通过 ATVV 蓝牙协议接收音频，写入 `Chromecast Mic`，并模拟长按 Fn，交给用户现有的微信全局语音输入功能转成文字。

使用前，需确保微信的长按 Fn 语音输入已能在其他软件中工作：

1. 点击目标软件的文本输入框。
2. 按住遥控器语音键说话，松开等待出字。
3. 用返回键回删，或短按静音键发送。

Remote Vibe 自身不调用云端识别接口、不保存录音或转写；微信语音的数据处理遵循微信自身设置和服务规则。

## 构建

当前构建目标为 **Apple Silicon、macOS 15 或更新版本**。只需要 Xcode Command Line Tools（Swift / Clang）和 macOS 自带工具，无额外构建依赖。

在本仓库根目录运行：

```sh
cd mac-app
zsh build.sh
open "build/Remote Vibe.app"
```

普通按键映射不需要安装驱动。单次 Esc、组合快捷键、滚动、换屏换窗、常用文本和连招功能使用系统的**输入监控**与**辅助功能**权限；语音功能还需要蓝牙权限、辅助功能权限，以及下述音频组件。

只在配置了上述需要监听的动作时启用按键监听。缺少所需权限时，这些键暂不执行；界面会提示授权。其他软件若改动同一按键，本 App 会提示重新保存，不会持续覆盖其设置。窗口只在动作触发时查询，不在后台轮询窗口或读取窗口内容。

### 语音组件（仅首次使用语音时）

在 `mac-app` 目录中运行：

```sh
zsh Driver/build-driver.sh
sudo zsh install-driver.sh
```

安装仅添加 `/Library/Audio/Plug-Ins/HAL/RemoteVibeMic.driver`，遇到已有同名组件会拒绝覆盖，并会重启 CoreAudio。不会安装内核扩展，也不会新增开机启动项。该组件只能作为默认输入设备，不能成为默认扬声器。

微信应使用系统默认输入，或选择 `Chromecast Mic`。App 在语音开始时切换默认输入，结束后尽可能恢复先前仍可用的输入设备。

## 保存与移除

- 按键配置及常用文本保存在用户偏好域 `local.ben.RemoteVibe` 的 `keyMappings.v1`，不在项目目录中写配置；旧配置可继续使用。
- 连招、密码与验证记录位于本机钥匙串服务 `local.ben.RemoteVibe.unlock`；偏好中只保存解锁开关。
- 运行状态在 `~/Library/Application Support/RemoteVibe/status.json`，仅包含设备和计数信息，只在状态改变时写入。
- 点击 **恢复此键默认**，再保存，可撤销某个按键的自定义设置。
- 从菜单栏退出 App，会停止监听并撤销本次仍在接管的按键设置；语音结束后停止音频输出，空闲时不持续发送静音。
- 卸载音频组件：退出 App 后，在 `mac-app` 中运行 `sudo zsh uninstall-driver.sh`。组件会移动到本机 `build/disabled/`，保留撤销路径。

当前构建使用本地签名，尚未签名公证用于公开二进制分发。应用标识保持不变，以兼容已授权的本机安装。

## 目录

```text
mac-app/
  Sources/                当前 App 源码
  Resources/              App 图标 PNG 与 ICNS
  Driver/                 虚拟麦克风源码及上游许可证
  Tests/                  已有的 Fn 与音频组件验证代码
  build.sh                原生 App 构建
  install-driver.sh       安装可选语音组件
  uninstall-driver.sh     移除语音组件
```

`build/`、早期录音、研究记录、本机日志与本机备份均排除在 Git 提交之外。核心 App 无外部包依赖，不需要包管理器。现有验证代码不参与正常构建。

## 已验证与限制

- 同一只 Chromecast Remote 上的遥控器收音、微信出字、静音键发送、返回键删除已通过实际操作验证。
- 配置界面、所有按键的映射表与保存逻辑已接入；未声称所有自定义快捷键在每个软件中都已实测。
- 双屏切换、同屏三个窗口循环（包含微信的两个窗口）已在本机验证；其他窗口布局和全屏 / Spaces 组合仍以实际系统行为为准。
- 常用文本已在原生文本框验证多行中文、英文、emoji、剪贴板恢复及保留新复制内容；设置页切换按键后的草稿保留也已验证。
- 连招匹配、超时和冷却已通过本地检查；真实遥控器录制接管 / 取消恢复、钥匙串样本保存 / 清除及默认关闭开关已验证。
- 连招解锁的真实锁屏投递由用户自行验证，默认关闭；程序发送事件不代表系统已接收或解锁成功。
- 图标使用 TDream 生成并转换为 macOS 图标，视觉效果由人工验收。
- 遥控器 VID / PID 为 `0x18D1 / 0x9450`，其他遥控器型号暂不支持。
- 如果某些按键被遥控器配置为红外控制，它们可能不向 Mac 发送蓝牙事件，此时无法由本 App 映射。
