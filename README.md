# Remote Vibe

让 Google Chromecast Voice Remote 和小米 RC003 在 Mac 上使用自带麦克风输入文字。两种型号均可按图配置快捷键。

原生 Swift / AppKit 应用，无 Web 服务、Electron 或第三方运行时。按键映射使用 macOS 原生 HID 接口，配置界面和蓝牙语音在同一个菜单栏 App 中运行。

0.3.1 常驻优化、CPU 实测与验证范围见 [性能核查](Docs/PERFORMANCE.md)。

## 使用

当前是面向有一定 Mac 操作基础用户的内部试用版。需自行完成蓝牙配对、系统权限与微信全局语音配置，暂不适合零基础开箱即用。

1. 在 macOS 蓝牙设置中配对 **Chromecast Remote** 或 **小米蓝牙语音遥控器（RC003）**。
2. 启动 Remote Vibe，在 **当前遥控器** 中选择 Google 或小米 RC003。App 一次连接所选的一种，并记住选择；旧配置默认选 Google。
3. 点击需要输入的文本框，按住所选遥控器的语音键说话，松开后等待微信出字。

App 自动连接已记住或系统已连接的所选型号，不自动扫描新设备。需要发现设备时点 **扫描遥控器**，最多扫描 20 秒，连接或超时即停止；可手动停止。若正在等待旧设备，先 **取消等待** 再扫描。每种型号分别记住已成功协商的设备 ID；断开后定向重连，不启动发现扫描。连续连接失败最多重试三次，之后等待手动操作。

切换型号不会覆盖 Google 按键配置。配置图随型号切换；Google 与小米的按键设置分别保存。Google 的连招设置保留。语音及收尾期间暂停切换型号。

在设置窗口中点击遥控器上的按键，选择 **单击 / 双击 / 长按**，分别配置功能，点击 **保存并生效**。小米图包含 12 个普通按键和固定语音键，布局根据 RC003 对应的代码资料绘制，外观由人工验收。

Google 的 15 个物理按键全部显示，包括侧边音量键。14 个普通按键可配置；语音键固定为按住说话。

**Google 默认键位：**

| 按键 | 默认功能 |
| --- | --- |
| 语音 | 按住说话，松开结束 |
| 静音 | Enter 回车 / 发送 |
| 独立返回箭头 | Backspace 退格删除 |
| 中央 OK | Esc，取消 / 停止，长按不连发 |
| 主页 | 循环切换当前屏幕窗口 |
| YouTube | 切换屏幕 |
| 方向盘 | 上、下、左、右 |
| 其他按键 | 保留原按键功能 |

**小米默认键位：**

- 中央确认 → Enter 回车；返回 → Backspace 退格。
- 方向、电源、音量、主页、菜单、TV → 原按键功能，可自行改绑。
- 语音 → 按住说话，松开结束。

可选动作按基本按键、剪贴板与编辑、搜索、应用与窗口、网页与标签、滚动与光标、截屏与系统、音量亮度媒体、自定义分类。已有配置优先于默认值，新增动作由用户自行绑定。

自定义支持 Control、Shift、Option、Command、Fn 多选，与字母、数字、方向键、F1–F20、标点及数字小键盘组合。例如为某个按键配置 `Fn + ↑` 或 `Control + Shift + ↑`，界面会预览完整组合。下拉菜单也提供 Shift + Tab、Command + Tab / Command + Shift + Tab、Control + Tab / Control + Shift + Tab 常用组合。

0.3.2 新增 **Fn（按住 / 松开）**：在功能列表选择它，或在自定义主键中选择 Fn。按住该普通键保持 Fn，松开释放；整个按键映射为 Fn，不保留另外的短按动作。Google 和小米均支持，分别保存。单独 Fn 的修饰键选项禁用；需要 Fn + 其他键时，选择其他主键并勾选 Fn。

Fn 的实际用途由 macOS 和当前软件设置决定。如果用它触发微信语音，将使用微信当前选择的输入设备；这项映射不启动遥控器麦克风、不切换系统输入。原语音键和下述“遥控器语音”动作负责遥控器收音。单独 Fn 正被按住时不接管另一段遥控器语音，避免两路输入互相中断。

Fn 通过系统按键事件模拟，需输入监控和辅助功能权限。松手、断连、保存设置、切换型号、暂停动作或退出时释放 App 接管的 Fn。单独映射为 Fn 的即时保持模式不使用长按定时器。

Esc、组合键、换屏和换窗按一次触发一次，长按不连发。组合键触发后会释放模拟的修饰键，同时保留键盘上实际按住的修饰键。

映射作用于当前软件；Enter 是否发送以及快捷键的行为由该软件决定。点击保存后，配置会保存在本机，运行期间在遥控器重连后恢复映射。正常退出时撤销 App 仍在接管的按键，并保留其他工具后来做的修改。设置窗口可关闭，App 继续在菜单栏运行。

### 用普通键说话（Google）

0.4.1 新增 **遥控器语音（按住说话）**。它会打开 Google 遥控器自带麦克风，并使用与原语音键相同的微信 Fn 输入、尾音排空和默认麦克风恢复流程。

- **保留短按功能，长按说话：**选择一个普通键，给单击选择明确动作（如 Enter 或“不执行”），再给长按选择 **遥控器语音（长按后开麦）**。按住约 0.55 秒开始，松开结束。
- **整颗键用于说话：**在单击位选择 **遥控器语音（按住说话）**，双击和长按均设为“未设置”。按下即请求开麦，松开结束。
- 双击不提供保持式语音。普通 **Fn** 动作保留原语义，不会自动升级为遥控器语音。
- 只有向 Mac 发送蓝牙按键事件的普通键才能使用。已有默认键位不会自动改变。

新动作目前仅在 Google 的配置图中提供，针对本机已实测的 ATVV 1.0 软件开麦；ATVV 0.4 和小米 RC003 继续使用原语音键，两款遥控器的配置独立保存。语音正在开始、收音或排空时，其他软件动作不能开启第二段语音。

开麦无响应或没有收到音频时自动取消；快速松手后，迟到的 ATVV 1.0 软件开麦响应会被关闭，原语音键不受软件重试等待影响。每次沿用 55 秒上限；按键松开时关麦并接收短暂在途音频后排空。若 0.4 秒内没有关麦确认，按原流编号重试一次；再等 0.4 秒仍无确认时报告异常并断开当前语音连接，不报正常结束。保存配置、按键监听丢失、切换型号、睡眠或退出时取消该按键的语音。空闲时不增加轮询，也不新增驱动。

本机 Google 的软件直接开麦已用独立程序实测成功；完整按键映射接入的自动化与人工验收边界见 [语音验证记录](Docs/GOOGLE-VOICE-VALIDATION.md)。

### 单击、双击与长按

0.3.3 为 Google 和小米的全部普通按键增加独立的双击、长按动作。旧单击配置直接保留，双击和长按默认均为 **未设置**。语音键继续按住说话、松开结束。

- 未设置双击、长按：保留原有的即时响应和重复规则。
- 设置双击：第一次松开后等待 **0.3 秒**；在此期间再次按下并松开，只执行双击动作。没有第二次按下才执行单击。
- 只设置长按：短按松开即执行单击；按住 **0.55 秒**执行一次长按，松开不再补发单击。
- 同时设置两者：第二次按下也可以变成长按，此时只执行长按。启用了任一手势的按键均不连发，包括方向键和滚动动作。
- 每个触发方式可单独选择快捷键、常用文本、换屏、换窗等已有动作；选 **不执行** 会识别并消费该手势，选 **未设置** 则关闭该手势识别。

例如，把中央确认设为 **单击 → Enter、双击 → 输入常用文本、长按 → Fn**。长按 Fn 达到 0.55 秒后保持，松开即释放；它使用目标软件当前的麦克风，不启动遥控器收音。

启用双击或长按时，单击必须选择明确动作（也可以是 **不执行**）。**原按键功能** 由系统直接处理，不能可靠地延迟后重放，因此界面会要求先改选单击动作。单击为 **Fn（按住 / 松开）** 时仍需即时保持，不能同时设置其他手势；可以把 Fn 移到长按。双击不支持保持 Fn。

三个触发方式的草稿与常用文本独立保留；**恢复此键默认** 会恢复单击并清除双击、长按，点击保存后生效。Google 与小米仍分别保存。新手势需要输入监控和辅助功能权限。

手势只在按键期间创建一次性定时器，没有新增空闲轮询。保存配置、切换型号、断连、进入语音或锁屏 / 连招录入、暂停、系统睡眠或退出时取消待执行手势，避免之后补发。

快捷键条目直接显示所发送的组合；是否生效由当前应用和系统的快捷键设置决定。例如“另存为”发送 Shift + Command + S，部分应用使用其他组合时请选自定义；“粘贴并匹配样式”也遵循目标应用行为。关闭窗口、锁屏等动作仅在用户配置并触发该按键后执行。

**打开指定应用**：选择 `.app` 后保存，触发时打开并激活；已经运行时切换到它。每个手势可以选不同应用，路径保存在本机；应用被移动或删除后会提示重新选择。

**打开指定网页**：填写完整的 `http://` 或 `https://` 地址，保存后交给默认浏览器打开，可能新建标签页。网页地址按手势独立保存在本机。

音量、亮度与媒体动作发送成对的系统按下 / 松开事件，每次触发只执行一次。外接屏亮度、数字音频输出的音量和媒体控制取决于设备与应用支持。四向滚动在未配置额外手势时可按住连发；配置了双击或长按时每次只滚动一次。打开应用或网页的请求一旦交给系统，不会因随后松手而撤销。

### 换屏与换窗

- **切换屏幕**：按屏幕排列顺序循环，激活目标屏幕最前面的可见普通窗口。当前屏幕按前台窗口占面积最大的位置判断，没有前台窗口时按鼠标位置判断。
- **切换当前屏幕窗口**：在当前屏幕可见的普通窗口之间按稳定顺序循环，包括同一应用的多个窗口；关闭或移走的窗口会移出循环。
- 成功后鼠标移入目标窗口，不点击，方便继续滚动。不会移动窗口、恢复最小化窗口或主动跨桌面空间（Spaces）。
- 只有一块屏幕、没有目标窗口、权限不足或窗口无法激活时，在设置窗口的状态区域显示原因。语音期间不执行换屏、换窗或组合快捷键。

窗口操作使用公共辅助功能接口和当前可见窗口清单，无需屏幕录制权限。未提供可操作辅助功能窗口、或窗口位置无法唯一匹配的应用窗口会被跳过。不提供“回输入框”：macOS 没有所有应用都支持的通用接口。

### 常用文本

选择一个按键，将动作设为 **输入常用文本**，填写文字并保存。每个按键独立保存一段文本，支持多行、中文和 emoji。先把光标放入目标输入框，再按遥控器：按一次粘贴一次，不自动按回车。

仅向可通过辅助功能确认的可编辑、非密码输入框粘贴。语音、锁屏或连招录入期间暂停；焦点变化时取消。App 短暂使用剪贴板，约 0.6 秒后恢复原内容；期间用户新复制的内容会保留。剪贴板无法完整备份或超过 32 MiB 时不执行。未提供可编辑辅助功能元素、禁用粘贴或处理粘贴过慢的应用可能无法使用此动作。

### 连招解锁

Google 遥控器可在 **连招解锁** 页设置；小米当前提供按键映射和语音，未接入锁屏连招。

在此页设置：

1. 点击 **录制连招**，按遥控器 8–16 次，点击 **确认录制**，再重复一次。除语音和电源外的按键均可参与。
2. 使用 **练习** 检查手感；练习只核对按键，不锁屏、不输入密码。
3. 在安全输入框中填写本机登录密码并保存。连招与密码分别保存到本机钥匙串，不同步到 iCloud，不写入偏好、日志或剪贴板。
4. 如需真实解锁，点击 **开始手动锁屏验证**，在 90 秒内自行锁屏并输入连招。App 只尝试把系统密码框替换为一个测试字符，不按回车。清掉测试字符，使用键盘正常解锁后，在 App 中确认结果。
5. 确认看到测试字符后，才能手动打开 **开启连招解锁**。

长按只算一次；相邻按键间隔超过 3 秒或按错时从头输入，连续 5 次错误暂停 30 秒。录入和锁屏识别期间暂时接管普通按键，结束后恢复。关闭设置窗口或离开此页会结束录制与练习。

真实解锁默认关闭。只有确认系统处于锁屏、目标进程是 Apple 签名的 `loginwindow`、焦点是其安全密码框且钥匙串可读时，才会定向替换密码并提交一次。每次锁屏最多提交一次，不自动重试，也不会退回全局密码输入。无法确认条件时请使用键盘正常解锁。

此功能依赖当前 macOS 的锁屏输入和辅助功能行为，**未经本机手动验证不能视为可用**。不支持重启 / FileVault 首次登录；App 或系统更新、修改连招或密码后需要重新验证。关闭功能保留设置；**清除连招与密码** 仅删除本 App 的解锁钥匙串项目。

## 语音输入

收音来自**遥控器自带麦克风**。App 通过 ATVV 蓝牙协议接收音频，写入 `Chromecast Mic`，并模拟长按 Fn，交给用户现有的微信全局语音输入功能转成文字。

两种遥控器共用同一套音频组件和微信输入流程，无需为小米再装驱动。`Chromecast Mic` 是现有组件的设备名称，小米也使用它。

小米 RC003 的原始语音键是 F5。App 仅在选中小米且语音连接就绪后临时屏蔽该设备的 F5，由语音会话统一控制 Fn；切换型号、断连或退出时恢复本次仍在接管的映射。不会修改其他键盘的 F5，亦不会持续覆盖其他映射工具的新改动。每次语音沿用 55 秒上限，需继续时松开后重新按住。

使用前，需确保微信的长按 Fn 语音输入已能在其他软件中工作：

1. 点击目标软件的文本输入框。
2. 按住遥控器语音键说话，松开等待出字。
3. 用返回键回删，或短按静音键发送。

Remote Vibe 自身不调用云端识别接口、不保存录音或转写；微信语音的数据处理遵循微信自身设置和服务规则。

## 构建

当前构建目标为 **Apple Silicon、macOS 15 或更新版本**。只需要 Xcode Command Line Tools（Swift / Clang）和 macOS 自带工具，无额外构建依赖。

在本仓库根目录运行：

```sh
zsh Scripts/build-app.sh
open "build/Remote Vibe.app"
```

普通按键映射不需要安装驱动。单次 Esc、组合快捷键、滚动、换屏换窗、常用文本和连招功能使用系统的**输入监控**与**辅助功能**权限；语音功能还需要蓝牙权限、辅助功能权限，以及下述音频组件。

只在配置了上述需要监听的动作时启用按键监听。缺少所需权限时，这些键暂不执行；界面会提示授权。其他软件若改动同一按键，本 App 会提示重新保存，不会持续覆盖其设置。窗口只在动作触发时查询，不在后台轮询窗口或读取窗口内容。

### 语音组件（仅首次使用语音时）

在本仓库根目录运行：

```sh
zsh Scripts/build-driver.sh
sudo zsh Scripts/install-driver.sh
```

安装仅添加 `/Library/Audio/Plug-Ins/HAL/RemoteVibeMic.driver`，遇到已有同名组件会拒绝覆盖，并会重启 CoreAudio。不会安装内核扩展，也不会新增开机启动项。该组件只能作为默认输入设备，不能成为默认扬声器。

微信应使用系统默认输入，或选择 `Chromecast Mic`。App 在语音开始时切换默认输入，结束后尽可能恢复先前仍可用的输入设备。

**音频影响：** 当前语音流程会临时改变系统默认麦克风，跟随默认输入的会议或录音软件可能受影响。结束恢复不等于过程无影响；原设备拔出、崩溃/强制结束等情况下无法保证即时恢复。并行会议/录音请在对应软件内指定实体麦克风。安装/卸载还会重启系统音频服务，可能短暂打断播放与录音。当前版本不承诺对所有音频软件零影响。

正常语音期间切换输入是设计行为。本机已观察到 AirPods → 遥控器 → AirPods 的正常恢复，输出保持原设备；完整依据和边界见 [音频设备核查](Docs/AUDIO-BEHAVIOR.md)。

## 保存与移除

- 按键配置、常用文本、所选应用路径与网页地址保存在用户偏好域 `local.ben.RemoteVibe` 的 `keyMappings.v1`，不在项目目录中写配置；旧配置可继续使用。双击、长按作为每个按键的可选字段保存，不覆盖单击字段。回退到不认识新动作类型的旧版前，请先备份偏好并恢复对应版本的配置快照。
- 所选遥控器型号保存在同一偏好域的 `voiceRemote.v1`。小米按键配置保存在 `keyMappings.xiaomiRC003.v1`，与 Google 的 `keyMappings.v1` 隔离；切换时只应用当前型号的配置。
- 已成功连接的蓝牙设备 ID 分型号保存在 `voicePeripheral.<型号>.v1`，仅用于本机定向重连。
- 连招、密码与验证记录位于本机钥匙串服务 `local.ben.RemoteVibe.unlock`；偏好中只保存解锁开关。
- 运行状态在 `~/Library/Application Support/RemoteVibe/status.json`，仅包含设备和计数信息，只在状态改变时写入。
- 点击 **恢复此键默认**，再保存，可撤销某个按键的自定义设置。
- 从菜单栏退出 App，会停止监听并撤销本次仍在接管的按键设置；语音结束后停止音频输出，空闲时不持续发送静音。
- 卸载音频组件：退出 App 后，在仓库根目录运行 `sudo zsh Scripts/uninstall-driver.sh`。组件会移动到本机 `build/disabled/`，保留撤销路径。

当前构建使用本地签名，尚未签名公证用于公开二进制分发。应用标识保持不变，以兼容已授权的本机安装。

运行语音会话测试：`zsh Tests/test-remote-voice.sh`。使用模拟协议消息和可控时钟，覆盖开关麦、迟到响应、超时、取消、尾音及 Google / 小米原语音链路，不访问蓝牙或声卡。

运行手势、动作库与设置页检查：`zsh Tests/test-button-gestures.sh`。测试使用模拟按键流与离屏 AppKit 控件，检查快捷键与媒体事件、应用路径与网址参数；不发送系统按键、不打开目标应用或网页、不修改设备映射或用户配置。设置页预览保存在 `build/tests/`。

- 两种配置图、各自的映射表与保存逻辑已接入；小米 12 键报告解析及语音报告排除已通过代码检查，未声称每个实体键及所有快捷键在每个软件中都已实测。
- 已通过 App 实际操作验证小米键位保存、Google / 小米切换、配置恢复及恢复默认；切到 Google 时，小米的临时 HID 映射撤销，Google 原配置保持一致。
